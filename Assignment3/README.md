This repository contains the code and report for Assignment 3, comparing DBSCAN with k-Means and Hierarchical Clustering algorithms.

## 📌 Contents
- Report: PDF document with:
  - DBSCAN algorithm overview
  - Comparative analysis and visualizations
  - Expanded comparison table
- Code: Jupyter Notebook/Python scripts for:
  - Dataset generation (`make_moons`, `make_blobs`)
  - Clustering implementations (DBSCAN, k-Means, Agglomerative)
  - Visualization of results
